# Watch and phone application

See the [root README](../README.md) for the current build instructions, architecture, contribution history, and limitations.

Open `FormFitWatch/FormFitWatch.xcodeproj` and select `FormFitPhone`. The app includes the watch target. Real sensor recording and WatchConnectivity verification require a paired physical iPhone and Apple Watch.

The app comes from our team's `codex-formfit-ui-watch-sync` branch and includes experimental Core ML inference and workout graphs. It still needs physical-device testing and model validation.
